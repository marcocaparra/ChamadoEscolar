# Contexto para trabalhar no PAD

- Leia [STATUS.md](STATUS.md) para saber o que já existe, o que foi sugerido e quais decisões estão abertas. Use o [README](README.md) para configurar e iniciar o projeto.
- Ao editar o painel em `web/painel.html`, sincronize o HTML com o bloco `v3_html` em `node-red/flows.json`. Preserve o cadastro e as configurações locais se atualizar o fluxo em uso.
- Mantenha fora do Git o `config.h` real, as credenciais do Telegram, o cadastro real e o histórico em `.node-red/`.
- Atualize o `STATUS.md` quando uma entrega mudar de situação ou uma decisão de projeto for tomada.
